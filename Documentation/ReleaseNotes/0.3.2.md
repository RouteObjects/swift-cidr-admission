# swift-cidr-admission 0.3.2

`0.3.2` adds a runnable SwiftNIO egress admission example and its documentation
and validation coverage. The library implementation, public APIs, policy
semantics, dependency requirements, and minimum supported toolchain are
unchanged from `0.3.1`.

## SwiftNIO egress admission example

- Add the separate `Examples/NIOTCPEgressAdmissionClient` package, a companion
  to the existing TCP echo server.
- Check every concrete destination in NIO's connect hook before forwarding
  the socket connection attempt, including resolved hostname candidates and
  Happy Eyeballs fallback attempts.
- Use async/await for connection setup and the bounded, newline-framed echo
  exchange, with connection and response deadlines and cancellation cleanup.
- Load allow/deny list files once before DNS or connection setup, require
  detached SHA-256 checksums, and preserve deny precedence and a deny default.
  The bundled policy allows only IPv4 and IPv6 loopback destinations.
- Include numbered integration comments, paired-server commands, custom-policy
  instructions, and a deny-before-connect experiment.

This demonstrates destination-IP admission, not port authorization, TLS peer
authentication, proxy-target enforcement, or a replacement for network egress
controls. Checksums verify integrity relative to the supplied checksum, not
producer authentication.

## Validation and documentation

- Add 25 client tests covering admission, DNS fallback, policy-file checksums,
  framing, deadlines, cancellation, and channel cleanup.
- Extend Linux/macOS CI and the release gate with client Debug/Release tests
  and lockfile verification, plus an iOS 18 compile-only CI check.
- Bind test loopback listeners directly to literal socket addresses so IPv6
  tests do not depend on hostname-resolution address-family filtering.
- Cross-link the runnable examples from the root README and example index.

## Compatibility

Use `.upToNextMinor(from: "0.3.2")` for `swift-cidr-admission`. Swift 6.2 remains
the library minimum; Apple deployment targets remain iOS 18 and macOS 15.
Dependencies remain `swift-cidr` 0.8.x from 0.8.1 and Swift Crypto 5.x from 5.0.3.
The optional benchmark package still requires Swift 6.3 or later.

The client is a nested example package, not a new public library product or a
new direct dependency of the root package. Existing dependency pins and
historical benchmark measurements are unchanged. No experimental
`decision(for:)` optimization or new benchmark snapshot is included.

This is a Swift library source release with no prebuilt binary assets.
