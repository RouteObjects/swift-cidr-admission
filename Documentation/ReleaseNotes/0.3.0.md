# swift-cidr-admission 0.3.0

`0.3.0` updates the supported toolchain and dependency graph while preserving
the 0.2 admission APIs and intended policy semantics. The new minor version
makes the Swift 6.2 minimum explicit rather than introducing that compatibility
change in a 0.2 patch release.

## Compatibility

| Requirement | 0.2.0 | 0.3.0 |
| --- | --- | --- |
| Minimum Swift tools | 6.1 | 6.2 |
| `swift-cidr` | 0.5.x | 0.8.x, from 0.8.0 |
| Swift Crypto | 4.x, from 4.5.1 | 5.x, from 5.0.3 |
| Apple deployment targets | iOS 18, macOS 15 | Unchanged |

Consumers that need Swift 6.1 should retain
`.upToNextMinor(from: "0.2.0")`, which excludes this release. To migrate,
upgrade the toolchain and use `.upToNextMinor(from: "0.3.0")` for admission.
Applications with a direct `swift-cidr` dependency must also permit `0.8.x`;
explicit Swift Crypto constraints must permit `5.x` from `5.0.3`.

## Admission behavior

- Public admission API shapes and the legacy CIDR-only JSON format are unchanged.
- Address, network, and range rules retain their existing policy-file format.
- Deny rules still take precedence. Detailed decisions retain first-source-rule
  diagnostics, and indexed Boolean lookups preserve the same exact coverage.
- Deprecated CIDR containment calls are replaced with explicit host-address
  projections. A peer's optional prefix context does not change whether its
  address bits match a network admission rule.
- Twelve parameterized IPv4/IPv6 regression cases cover broad and host prefix
  contexts, boundaries, mixed-family non-matches, and agreement between rule
  containment, indexed lookups, and detailed allow/deny decisions.

Detached SHA-256 verification continues to use the existing `Data` hashing
path. This release does not adopt span-based hashing or claim a hashing or
lookup performance improvement.

## Benchmarks and release validation

The optional benchmark package requires Swift 6.3 or later. Benchmark 1.35's
Swift 6.2 compatibility manifest requires ArgumentParser below `1.6.0`, which
conflicts with `swift-cidr` 0.8.x's requirement of `1.7.0` or later. Swift 6.3
selects Benchmark's compatible manifest. Library consumers need only Swift 6.2.

Minimum-toolchain Linux CI uses Swift 6.2.4 for debug/release tests, dependency
lock verification, offline `cidrmerge` 0.2.0 pipeline acceptance, and the
SwiftNIO example. Benchmark CI and the complete release gate use Swift 6.3.3.
Manually dispatched Apple CI selects Xcode 26.3 and includes the iOS 18
simulator build.

The complete release gate also covers license and dependency hygiene, public
symbol extraction, and an external consumer. Candidate commit IDs and verified
local/hosted validation results are recorded in the release-preparation PR.
Historical benchmark measurements remain historical; no new timing results
are included in this release.

This is a Swift library source release with no prebuilt binary assets. It does
not add policy fetching, hot reload, producer authentication, or audit metrics.
