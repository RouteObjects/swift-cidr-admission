# swift-cidr-admission 0.3.1

`0.3.1` is a dependency and benchmark-tooling maintenance release. It includes
the typed-containment performance fix from `swift-cidr` 0.8.1 without changing
the admission implementation, public APIs, or policy semantics.

## Dependency update

- Require `swift-cidr` 0.8.1 within the existing 0.8.x compatibility range in
  the root package, benchmarks, SwiftNIO example, and pipeline acceptance package.
- Update all four lockfiles to the published 0.8.1 commit. Other committed
  dependency pins are unchanged by this CIDR update.
- Include the upstream fix that enables downstream optimization of ordinary
  typed prefix-containment calls. Consumers do not need an alternate wrapper
  API to obtain the fix.

The minimum supported toolchain remains Swift 6.2. Apple deployment targets
remain iOS 18 and macOS 15, and Swift Crypto remains 5.x from 5.0.3.

Use `.upToNextMinor(from: "0.3.1")` for `swift-cidr-admission`. Applications
that also depend directly on `swift-cidr` should permit 0.8.x from 0.8.1.

## Benchmark tooling

The optional benchmark package now uses Benchmark 1.38.1 and still requires
Swift 6.3 or later. The 10,000-entry detailed-decision cases use single-operation
batches to improve sampling within the configured time window. These tooling
changes do not add instrumentation to library consumers.

Historical benchmark measurements are unchanged. This release does not
publish new timing results or make a universal lookup-performance guarantee.

## Unchanged behavior

- Address, network, and range rules retain their existing formats and matching
  semantics, including IPv4/IPv6 family separation.
- Deny rules retain precedence, detailed decisions preserve first-source-rule
  diagnostics, and indexed Boolean lookups preserve exact coverage.
- Policy-file loading and detached SHA-256 verification are unchanged.

This is a Swift library source release with no prebuilt binary assets.
