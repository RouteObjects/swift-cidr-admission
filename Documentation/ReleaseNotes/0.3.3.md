# swift-cidr-admission 0.3.3

`0.3.3` normalizes the peer address once at entry to `IPAdmissionPolicy.decision(for:)`,
reducing repeated work during detailed network-rule scans. Public APIs, policy
semantics, dependency requirements, and minimum supported toolchains are
unchanged from `0.3.2`.

## Detailed decision evaluation

- Create one private host-only representation of the peer, using `/32` for
  IPv4 or `/128` for IPv6 while preserving the address bits.
- Reuse that representation across the deny scan and allow scan, with typed
  network containment and no per-rule normalization or cache-state checks.
- Preserve deny precedence, source-rule order, the first matched rule and its
  original prefix context in the decision reason, and the configured default.
- Preserve address, network, and range matching, IPv4/IPv6 separation, and
  IPv4-mapped IPv6 behavior. Public `AdmissionRule.contains(_:)` is unchanged.

Detailed decisions still scan the source arrays. The indexed Boolean
`allows(_:)` path is unchanged. Normalizing at entry reduces repeated work in
long network-rule scans, but adds a fixed setup cost even for empty policies
or early address/range matches. This is not a claim that every lookup becomes
faster, and no new benchmark snapshot is included in this release.

## Regression coverage

Add seven tests comparing complete decisions against the unchanged public-rule
scan and checking agreement with `allows(_:)`. Coverage includes every legal
peer prefix length for selected IPv4/IPv6 boundary addresses, overlapping and
mixed rule kinds, deny precedence, source-rule ordering and stored prefix
context, default actions, seeded policies, and repeated/concurrent evaluation.

## Compatibility

Use `.upToNextMinor(from: "0.3.3")` for `swift-cidr-admission`. Swift 6.2 remains
the library minimum; Apple deployment targets remain iOS 18 and macOS 15.
Dependencies remain `swift-cidr` 0.8.x from 0.8.1 and Swift Crypto 5.x from 5.0.3.
The optional benchmark package still requires Swift 6.3 or later.

No consumer migration is required from `0.3.2`. Dependency pins, nested SwiftNIO
examples, and historical benchmark measurements are unchanged.

This is a Swift library source release with no prebuilt binary assets.
